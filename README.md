Fulcrum is a cloud manufacturing ERP/MES platform for precision manufacturers — CNC machining shops, sheet metal fabricators, and job shops — connecting shop-floor operations to live data for quoting, sales orders, scheduling (Autoschedule), job costing, BOM and routing, quality (AS9100D/ISO 9001), inventory, purchasing, and invoicing. The Fulcrum Public API is a REST API (base URL https://api.fulcrumpro.com/api/) with 454 operations across items, sales orders, quotes, jobs, purchase orders, invoices, vendors, and customers, authenticated with site-scoped bearer JWT tokens and returning RFC 9457 problem+json errors. Fulcrum also publishes an official MCP server that connects Claude and ChatGPT directly to a Fulcrum site. Headquartered in Minneapolis, Minnesota and backed by Battery Ventures; marketed as ITAR secure and CMMC 2.0 ready.

**Areas:** Company · Manufacturing · ERP · MES · Manufacturing Execution · Job Shop · CNC Machining · Sheet Metal · Inventory · Purchasing · Quoting · Scheduling
