# Fulcrum

> Fulcrum is a cloud manufacturing ERP/MES platform for precision manufacturers (CNC machining, sheet metal fabrication, job shops). The Fulcrum Public API is a REST API for building integrations directly into a Fulcrum site — quoting, sales orders, jobs, scheduling, inventory, purchasing, and invoicing. Authentication is a site-scoped bearer JWT; errors follow RFC 9457 problem+json; list endpoints use offset pagination (Skip/Take).

## APIs
- [Fulcrum Public API](https://developers.fulcrumpro.com/docs): REST API, base URL https://api.fulcrumpro.com/api/ — 454 operations across items, sales orders, quotes, jobs, purchase orders, invoices, vendors, customers, inventory, and reporting.
